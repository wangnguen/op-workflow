Bản preview đầu tiên của op-workflow, app desktop điều phối Claude Code và Codex theo quy trình làm task OpenProject. Chỉ chạy trên Windows 10/11 x64.

> **Pre-release:** bản dùng thử. Chưa chạy được quy trình làm task thật; định dạng cấu hình và dữ liệu có thể còn đổi trước 1.0.

## Điểm chính

- **Task OpenProject thật, chỉ đọc:** nhập URL OpenProject và token ở **Cài đặt** (biểu tượng bánh răng). App kiểm tra token rồi lưu vào Windows Credential Manager, sau đó hiện các task đang mở giao cho bạn ở mọi project. App không ghi gì lên OpenProject (không comment, không đổi trạng thái).
- **Quota realtime:** % còn lại của Claude (5 giờ / 7 ngày) và Codex (5 giờ / 7 ngày) trên thanh trên. App không đọc OAuth token của CLI: Codex lấy qua `codex app-server`, Claude qua một probe nhỏ bằng Haiku 15 phút một lần.
- **Quy trình 8 bước (bản demo):** Implement → `/review-local` → Claude sửa → Codex review ⇄ Claude sửa → `/review-local` chốt → `/push-summary`. Có bảng task, màn Phiên (Bảng / Quỹ đạo) và popup Hạn mức. Phần quy trình hiện vẫn chạy bằng dữ liệu demo.
- **Không bao giờ tự commit hay push:** mọi tiến trình AI do app chạy đều bị chặn commit/push ở mức biến môi trường git (ADR 0002).
- **Chẩn đoán:** `op-workflow-desktop.exe --live-check` (quota, OpenProject có kết nối được không) và `--pty-selftest` (TUI claude/codex trong ConPTY, ADR 0003).

## Giới hạn đã biết

- "Bắt đầu làm việc" vẫn là hộp thoại demo: chưa tạo branch, chưa chạy Analyze / Implement / review từ app.
- Cần cài sẵn Claude Code CLI và Codex CLI, và đã đăng nhập, thì mới có quota.
- Bản build **chưa ký số**. SmartScreen có thể cảnh báo. Phần mềm diệt virus có thể cách ly file cài hoặc file exe; khi đó cần thêm ngoại lệ (hoặc nhờ IT).

## Cài đặt

| File | Dùng để |
|---|---|
| `op-workflow_0.1.0_x64-setup.exe` | Bản cài (cài cho người dùng hiện tại, không cần quyền admin) |
| `SHA256SUMS.txt` | Mã băm để kiểm tra file tải về |

Nếu Windows SmartScreen hiện "Windows protected your PC", bấm **More info → Run anyway**. Chỉ tải từ trang release này, và kiểm tra mã băm trước khi cài:

```powershell
Get-FileHash .\op-workflow_0.1.0_x64-setup.exe -Algorithm SHA256   # so với SHA256SUMS.txt
```

Cần WebView2: Windows 11 có sẵn, còn nếu máy thiếu thì bản cài tự tải.

Dữ liệu và cấu hình nằm ở `%USERPROFILE%\.op-workflow\`. Token OpenProject nằm trong Windows Credential Manager, mục `op-workflow`. Gỡ cài đặt: Settings → Apps → op-workflow.
