Bản preview thứ ba của op-workflow. Từ bản này, các bước AI chạy ngay trong app: phân tích, viết code, kiểm tra, review, sửa lỗi, test và viết commit message, mỗi bước dừng để bạn xem và quyết. Màn **Workspace** mới cho mỗi task một phiên Claude Code như trong extension VS Code. Chỉ chạy trên Windows 10/11 x64.

> **Pre-release:** bản dùng thử. Luồng các bước và màn Workspace mới chạy trên ít task thật; định dạng cấu hình và dữ liệu có thể còn đổi trước 1.0. App vẫn chỉ **đọc** OpenProject và **không bao giờ commit hay push**.

## Điểm chính

- **Luồng 12 bước:** Nhận task → Phân tích → Viết code → Kiểm tra → Harness → Tự review → Sửa lỗi → Review chéo → Sửa lỗi → Test trình duyệt → Review chốt → Push summary. Mặc định dừng sau mỗi bước; bật *Tự chạy* thì app chỉ dừng ở chỗ cần bạn quyết.
- **Bạn quyết ở mỗi cổng:** duyệt plan (trả lời câu hỏi AI đặt ra, góp ý, hoặc tự code), chọn lỗi nào cho AI sửa sau mỗi review (kèm nguồn, bước, vòng), hỏi có review chéo lại sau mỗi lần sửa. Bước nào lỗi cũng hỏi được AI ngay tại đó rồi chạy tiếp theo hướng đã bàn; bấm *Dừng* giữa chừng thì dặn thêm rồi *Chạy tiếp* trong cùng phiên.
- **Kiểm tra** chạy typecheck / lint / prettier trên phần task đổi (không tốn token), AI tự sửa lỗi tìm thấy. **Harness** (khi task cần) dựng test ngoài repo theo brief và plan, AI còn lại review harness trước khi app chạy nó. **Test trình duyệt** (khi task cần): app bật dev server theo danh sách lệnh của repo và mở một cửa sổ Chrome riêng, AI thử thay đổi qua Chrome DevTools MCP, chụp ảnh ca lỗi.
- **Push summary** viết commit message và mô tả PR, có nút copy. Bạn tự review diff, commit, push rồi bấm *Đã push xong*; app kiểm tra nhánh đã lên origin chưa.
- **Chọn AI theo bước** ở Cài đặt → Các bước AI: Claude hoặc Codex, model, effort, chế độ quyền, trần chi phí và thời gian; danh sách đọc từ CLI trên máy bạn. Review chéo mặc định dùng AI khác AI đã viết code.
- **Workspace:** cây project → task → phiên, thêm *Phiên riêng* không gắn task. Cửa sổ chat như extension: hộp duyệt quyền, câu hỏi, duyệt plan, chọn chế độ quyền, dán ảnh, gợi ý `@` file và `/` lệnh. Tab *Terminal của phiên* (Claude Code trong terminal), *Shell* ở thư mục repo (script trong `package.json` thành nút), *Thay đổi* (mở hoặc so sánh từng file trong VS Code), *Brief*, *Comment* (mỗi comment có *Hỏi Claude*). *Mở trong VS Code* mở tiếp đúng phiên trong extension. Thông báo Windows khi một phiên chờ bạn.
- **Bảng task:** kéo thả thẻ giữa các cột, cột *Đã xong*, *Làm tiếp* một task đã xong, *Làm lại từ đầu* trong phiên mới. Thẻ Inbox có *Xem task*: đọc mô tả và comment trên OpenProject mà chưa cần bắt đầu task.
- **Comment và thông báo:** comment của bạn thu gọn, chỉ báo comment của người khác; mỗi comment có link mở trên OpenProject. Chuông có Chưa đọc / Tất cả / Đã xoá (khôi phục được trong 30 ngày). Hạn mức Claude / Codex trên khay hệ thống, nhắc trước khi chạy bước AI; hết hạn mức giữa bước thì tới giờ reset, bước chạy tiếp từ chỗ dở (Tự chạy bật thì tự chạy, tắt thì app báo bạn).
- **Giao diện:** mọi màu theo theme đang chọn (mặc định Catppuccin Macchiato), cửa sổ không viền với nút thu nhỏ / phóng to / đóng trên thanh trên, thanh bên kéo rộng hẹp hoặc ẩn được. Bấm X thì hỏi thu xuống khay (AI chạy tiếp) hay thoát hẳn (dừng AI và các tiến trình AI bật).

## Giới hạn đã biết

- Phiên trong Workspace chưa tự nhận brief khi bạn chat thường; brief chỉ được gửi khi chạy một bước của app. Đọc brief ở tab *Brief*.
- Cần cài sẵn Claude Code CLI và Codex CLI, và đã đăng nhập. *Test trình duyệt* cần Google Chrome; các nút *Mở trong VS Code* cần lệnh `code` trong PATH.
- Bản build **chưa ký số**. SmartScreen có thể cảnh báo. Phần mềm diệt virus có thể cách ly file cài hoặc file exe; khi đó cần thêm ngoại lệ (hoặc nhờ IT).

## Cài đặt

| File | Dùng để |
|---|---|
| `op-workflow_0.3.0_x64-setup.exe` | Bản cài (cài cho người dùng hiện tại, không cần quyền admin). Cài đè lên bản 0.2.0 được, dữ liệu giữ nguyên; task đã bắt đầu ở bản cũ chuyển sang luồng 12 bước |
| `SHA256SUMS.txt` | Mã băm để kiểm tra file tải về |

Nếu Windows SmartScreen hiện "Windows protected your PC", bấm **More info → Run anyway**. Chỉ tải từ trang release này, và kiểm tra mã băm trước khi cài:

```powershell
Get-FileHash .\op-workflow_0.3.0_x64-setup.exe -Algorithm SHA256   # so với SHA256SUMS.txt
```

Cần WebView2: Windows 11 có sẵn, còn nếu máy thiếu thì bản cài tự tải.

Dữ liệu và cấu hình nằm ở `%USERPROFILE%\.op-workflow\`. Token OpenProject nằm trong Windows Credential Manager, mục `op-workflow`. Gỡ cài đặt: Settings → Apps → op-workflow.
