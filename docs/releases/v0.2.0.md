Bản preview thứ hai của op-workflow. Từ bản này, nút "Bắt đầu làm việc" chạy thật: tạo branch ở máy và viết brief cho task. Chỉ chạy trên Windows 10/11 x64.

> **Pre-release:** bản dùng thử. Các bước AI sau bước 1 (phân tích, code, review) chưa chạy từ app; định dạng cấu hình và dữ liệu có thể còn đổi trước 1.0.

## Điểm chính

- **Bắt đầu làm việc thật:** app tìm repo trong thư mục workspace, gợi ý repo khớp link issue của task, cho chọn base ở hai tab Local / Remote, tạo branch ở máy (không push) và ghi `brief.md` (mô tả và comment OpenProject). Làm song song được nhiều task. App nhớ repo, base và mẫu tên branch cho lần sau.
- **Xoá nhánh** ngay trong danh sách nhánh: nhánh local (nhánh còn commit chưa merge phải xác nhận thêm) và nhánh trên origin (phải gõ đúng tên nhánh). Nhánh chính, nhánh đang đứng và nhánh của task đang làm thì không xoá được. Xoá nhánh trên origin là việc duy nhất app đẩy lên remote, và chỉ chạy khi bạn bấm.
- **Đọc issue GitHub qua Chrome của bạn:** nút "Lấy issue" (cũng tự chạy sau khi bắt đầu task) đọc tiêu đề, nội dung và comment của issue gắn trong task rồi ghi vào brief. Không token, không `gh`, không bấm hay sửa gì trên GitHub; bỏ tên người và `@mention`. Cần Chrome 144 trở lên và bật một lần ở `chrome://inspect/#remote-debugging`; mỗi lần đọc, Chrome hỏi **Allow**.
- **Thư mục brief chọn được:** lần đầu app hỏi có lưu brief ra `Desktop\op-workflow-tasks` cho dễ tìm không; đổi lại ở Cài đặt → Giới thiệu.
- **Màn Phiên:** bắt đầu task ngay tại đây (nút "Bắt đầu task"), task chờ bạn code hiện ở cột "Cần bạn". Chuyển Quỹ đạo ⇄ Bảng mượt, bản đồ giữ nguyên zoom và lựa chọn. Hành tinh trôi nhẹ trên quỹ đạo, nhãn không đè lên nhau; mục "Cách đọc bản đồ" gọn hơn.
- **Claude / Codex:** mỗi bên có trạng thái kết nối; nút "Kết nối lại", và "Đăng nhập" mở lệnh đăng nhập của CLI khi bị đăng xuất.
- **Giao diện:** theme Sáng / Tối / Theo hệ thống với các bảng màu quen thuộc (Dracula, Tokyo Night, Catppuccin, Nord, Gruvbox, Rosé Pine, One, Solarized, Monokai); nhãn trạng thái theo màu của OpenProject; Cài đặt mới có tìm kiếm; logo và icon app mới.
- **Kiểm tra bản mới:** app tự hỏi GitHub Releases vài giờ một lần và báo khi có bản mới (không tự tải, không tự cài).

## Giới hạn đã biết

- Sau bước 1 (tạo branch và brief), các bước AI còn lại chưa chạy từ app; bạn tự code trên nhánh vừa tạo.
- Cần cài sẵn Claude Code CLI và Codex CLI, và đã đăng nhập, thì mới có quota.
- Bản build **chưa ký số**. SmartScreen có thể cảnh báo. Phần mềm diệt virus có thể cách ly file cài hoặc file exe; khi đó cần thêm ngoại lệ (hoặc nhờ IT).

## Cài đặt

| File | Dùng để |
|---|---|
| `op-workflow_0.2.0_x64-setup.exe` | Bản cài (cài cho người dùng hiện tại, không cần quyền admin). Cài đè lên bản 0.1.0 được, dữ liệu giữ nguyên |
| `SHA256SUMS.txt` | Mã băm để kiểm tra file tải về |

Nếu Windows SmartScreen hiện "Windows protected your PC", bấm **More info → Run anyway**. Chỉ tải từ trang release này, và kiểm tra mã băm trước khi cài:

```powershell
Get-FileHash .\op-workflow_0.2.0_x64-setup.exe -Algorithm SHA256   # so với SHA256SUMS.txt
```

Cần WebView2: Windows 11 có sẵn, còn nếu máy thiếu thì bản cài tự tải.

Dữ liệu và cấu hình nằm ở `%USERPROFILE%\.op-workflow\`. Token OpenProject nằm trong Windows Credential Manager, mục `op-workflow`. Gỡ cài đặt: Settings → Apps → op-workflow.
